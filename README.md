# TClock-Win11（β）

TClock-Win10からフォークしたプロジェクトです。

- Windows 11 25H2でタスクバーを他のツールで変更していない環境向け（現状は人柱向け）

## 2026/03/14 主な変更点（v0.2.4.1）

- マウス操作のボタンクリックで、TClock表示領域に対する最大3分割の起動分岐を追加
- NMX1/NMX2 の書式を復活し、Windows 11 25H2 向けの修正を実施
- 設定画面のレイアウトを調整

## その他更新について

詳しい更新履歴は [CHANGELOG.md](CHANGELOG.md) を参照してください。
