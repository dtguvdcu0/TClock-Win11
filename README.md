# TClock-Win11（β）

TClock-Win10からフォークしたプロジェクトです。

- Windows 11 25H2でタスクバーを他のツールで変更していない環境向け（現状は人柱向け）

## 2026/09/30 主な変更点（v0.2.6.0）

- 横位置のタスクバーでのグラフ・メーターバー・時計を表示対応
- 書式の値に条件式を追加（詳細はリリースページを参照）
- WinUI表示時の文字描画を調整
- 付箋ツールの書式読込の一部修正
- その他軽微な修正

## その他更新について

詳しい更新履歴は [CHANGELOG.md](CHANGELOG.md) を参照してください。
