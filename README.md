# TClock-Win11（β）

TClock-Win10からフォークしたプロジェクトです。

* Windows 11 26H2でタスクバーを他のツールで変更していない環境向け（現状は人柱向け）

## 2026/11/22 主な変更点（v0.2.6.5）

* 自由に拡張できるプラグイン基盤の対応
* 時報の改良・修正
* 動作の軽量化・安定化・チラつき対策
* 祝日用の書式追加と既存判定の修正
* ビルトイン用の修正
* そのほか軽微な修正
