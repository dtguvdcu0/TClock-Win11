# TClock-Win11（β）

TClock-Win10からフォークしたプロジェクトです。

- Windows 11 25H2でタスクバーを他のツールで変更していない環境向け（現状は人柱向け）

## 2026/03/10 主な変更点（v0.2.4.0）

- ストレージ転送の書き/読み/総合の書式を追加
- ini関係の修正、暫定的な措置のUtf8Hexを限定化、初期で出力される項目の整理
- その他軽微な修正
