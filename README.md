# TClock-Win11（β）

TClock-Win10からフォークしたプロジェクトです。

- Windows 11 25H2でタスクバーを他のツールで変更していない環境向け（現状は人柱向け）

## 2026/09/19 Main changes (v0.2.5.6)

- タスクバーのWinUI設定時のZ座標処理の修正
- Tooltipのちらつきの解消
- TClock書式の使える付箋ツールTCard追加
- その他軽微な修正
