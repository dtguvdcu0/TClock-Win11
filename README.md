# TClock-Win11（β）

TClock-Win10からフォークしたプロジェクトです。

- Windows 11 26H2でタスクバーを他のツールで変更していない環境向け（現状は人柱向け）
- 簡単な解説サイト作成中

## 2026/10/18 主な変更点（v0.2.6.3）

- マルチディスプレイでのタスクバー境界線とWinUI対応
- ツールチップの位置・ホバーの設定追加
- 右クリックメニューの描画のちらつき抑制
- 接続通知によるIP・ネットワーク表示の取得タイミング修正
- 表示倍率による縦置き時計の位置ずれループ修正
- 終了時の不具合修正
- プラグインの分離
- そのほか軽微な修正
