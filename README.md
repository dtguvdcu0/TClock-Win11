# TClock-Win11（β）

TClock-Win10からフォークしたプロジェクトです。

- Windows 11 26H2でタスクバーを他のツールで変更していない環境向け（現状は人柱向け）
- 簡単な解説サイト作成中

## 2026/10/08 主な変更点（v0.2.6.2）

- 起動時の読込み最適化
- 拡張表示のタスクバー外の表示オプション追加
- 通信速度の自動単位の追加
- 背景色取得と境界線描画のタイミングの修正更新
- プラグインのUI改善
- その他軽微な修正と変更
