# TClock-Win11（β）

TClock-Win10からフォークしたプロジェクトです。

- Windows 11 25H2でタスクバーを他のツールで変更していない環境向け（現状は人柱向け）

## 2026/10/03 主な変更点（v0.2.6.1）

- フォント適応時の不具合の修正
- TClock領域に1pxのborderを追加してレイアウトの不整合感を修正
- 上下位置時の右端のデスクトップを表示、エリアの補完
- 右クリックメニューのカスタマイズをプロパティUI上での使用感改善
- カスタマイズ向けビルトイン一覧に「コントロールパネル:日付と時刻」、「時刻を同期」の追加
- 拡張表示としてアナログ時計やパラパラ時計など文字以外の時計を追加
