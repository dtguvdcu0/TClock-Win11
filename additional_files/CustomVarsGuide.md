# CustomVars User Guide

Last updated: 2026-03-08  
CustomVars lets TClock display text from external files inside the clock format.

## What You Can Do With CustomVars

Use CustomVars when you want the clock to show information that does not come from the built-in date and time format.

Typical uses:
- show weather text generated by another tool
- show one line from a text file
- show the latest value written by a script
- show selected values from a JSON file

## How It Works

You define variables under `[CustomVars]` in `tclock-win11.ini`.
Each variable is named `CUSTOM1` to `CUSTOM32` and can then be inserted into a clock format string.

For most users, `line` mode is the best starting point.
Use `json` mode only when you need structured data extraction.

## Minimal Example

```ini
[CustomVars]
Custom1Path=custom\custom_test.txt
Custom1Mode=line
Custom1FailValue=N/A
Custom1RefreshSec=10
Custom1MaxChars=20
```

If `custom\custom_test.txt` contains text on its first line, `CUSTOM1` will show that text.

## Use It In The Clock Format

```ini
[Format]
Custom=1
CustomFormat=yyyy/mm/dd(ddd) hh:nn:ss CUSTOM1
```

## Common Ways To Use It

### Show one line from a text file

Use:
- `CustomNMode=line`
- `CustomNPath=<path>`

This is the easiest and most reliable setup.

### Show data from a JSON file

Use:
- `CustomNMode=json`
- `CustomNJsonValue=...`

This is useful for data such as weather, script output, or simple status feeds.

## Main Keys

`N` means `1..32`.

- `CustomNPath=<path>`: source file path
- `CustomNMode=line|json`: read mode
- `CustomNFailValue=<text>`: fallback text on failure
- `CustomNRefreshSec=<int>`: refresh interval in seconds
- `CustomNMaxChars=<int>`: max output length

Global keys under `[CustomVars]`:
- `PreloadOnStartup=<0|1>`
- `RefreshSec=<int>`
- `MaxChars=<int>`

## JSON Mode Keys

- `CustomNJsonPath`
- `CustomNJsonType`
- `CustomNJsonDefault`
- `CustomNJsonValue`

Example:

```ini
[CustomVars]
Custom4Path=custom\weather_tokyo.json
Custom4Mode=json
Custom4JsonValue=Tokyo {$.weather.desc} {$.weather.temp_c}C {$.weather.humidity_pct}% Wind{$.weather.wind_mps}
Custom4JsonType=auto
Custom4FailValue=N/A
Custom4RefreshSec=60
Custom4MaxChars=20
```
