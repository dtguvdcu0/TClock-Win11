********
はじめに
********
・本ソフトウェアは、Windows11 25H2で動作するTClockです。

・本ソフトウェアは、
TClock (by Kazubon氏)
TClock2ch (by 2ch有志)
TClockLight (by K. Takata氏)
TClock-Win10 (by Mantis Mountain Mobile氏)
を参考にしWindows11 25H2で動作させるための修正を行ったバージョンになります。

・TClock系ソフトの歴史
TClock付属サイト(archive.org)：
https://web.archive.org/web/20260000000000*/http://tclock2ch.no.land.to/

・本プログラムが存在するのはひとえにKazubon氏、K.Takata氏、Mantis Mountain Mobile氏および多くのネット上の開発参加者の功績です。

・本ソフトウェアはフリーソフトで、GNU GPLに従って再配布または変更することができます。

************
利用上の注意
************

・ほかのTClock系ソフトと同様に、本ソフトを利用することによって生じた一切の損害等の責任は負いません。

・本ソフトのベースはTClock2chであり、TClockLight系(現在はTClockLight-kt)とは別の系統になります。書式等、TClockLight系と異なる点がありますのでご注意ください。

・ユーザ権限で操作可能なフォルダ(例：ユーザーアカウント内)に置いて運用することを想定しています。
Program Files等のWindows管理下のフォルダではなく、個人フォルダに置いて利用してください。
(Program Filesの中でも動くかもしれませんが、確認していません。)

・VC++ラインタイムパッケージについて
本ソフトウェアは、VC++のランタイムパッケージを必要とします。tclock-win11.exeをダブルクリックして
『VCRUNTIME140.dllが見つからないため、コードの実行を続行できません。…』
『MSVCP140.dllが見つからないため、コードの実行を続行できません。…』
というメッセージが出た場合は、Microsoftが配布している、
Visual Studio 2015 Visual C++ 再頒布可能パッケージ
https://www.microsoft.com/ja-jp/download/details.aspx?id=48145
をインストールしてください(64bit版ならvc_redist.x64.exe)。
(2019/4月現在のURL)

********************
アンインストール方法
********************

・フォルダごとファイルを消去してください。

・レジストリは使用していません。

・右クリックメニュー⇒『tclockのプロパティ』⇒『その他』タブにある『レジストリ削除』ボタンは有効です。
過去のTClock系ソフトによるレジストリエントリをまとめて消すことができます。

利用方法・設定変更方法

[TClock2ch由来の機能]
・基本的な利用方法やカスタム書式の考え方は、TClock付属サイト(archive.org)：
https://web.archive.org/web/20260000000000*/http://tclock2ch.no.land.to/

の、『TClock2chのヘルプ』も参照してください。

少なくとも、以下の点は旧来のバージョンと異なっています。
・TClock2chはWiFiのネットワーク送受信量を正しく検出できませんでしたが、対応しています。またネットワーク速度の折れ線グラフ表示で対数プロットができていなかったのを修正しました。

・TTBase連携機能、およびデスクトップカレンダーとの連携機能は廃止しました。利用できません。

・そのほか以下の機能を削除しています。	ウィンドウの配列・操作機能
	ツールチップへのWEB表示機能
	スタートボタンの改造や、スタートメニューの改造機能
	複数設定保存機能
	ボリューム調節機能
	時刻合わせ機能
	デスクトップアイコン改造機能

[現在の設定変更方法]
・通常の設定変更は、時計を右クリックして『TClockのプロパティ』を開き、各プロパティページから行ってください。
・起動オプション /prop でもプロパティダイアログを開けます。
・書式、マウス操作、グラフ、ツールチップ、アナログ時計、チャイム、バー表示、Windows11対応、キーワード、その他の多くの項目はプロパティから設定できます。
・iniファイルの手動編集は、このREADMEで「ini編集のみ」「手動設定用」などと説明している項目や、トラブル対応・詳細調整が必要な場合に限定することをお勧めします。
・iniを手動編集した場合、反映されないときはTClockを再起動してください。大きく変更する場合は、事前に tclock-win11.ini のコピーを保存しておくことをお勧めします。

[iniファイル]
・tclock-win11ではiniファイル(tclock-win11.ini)に完全移行しており、iniファイルを自動作成します。作成失敗すると起動できません。
・iniファイルはUTF-8で扱います。日本語文字列やパスを手動編集する場合は、文字コードを変えないようにしてください。
・下記の「値はデフォルト値」は、内蔵の既定値を示します。近年のバージョンでは、初期値と同じ行をiniに書かない項目があります。
・iniに存在しない項目は、多くの場合「内蔵の既定値を使う」という意味です。READMEに載っている項目を、存在しないからという理由だけで追加する必要はありません。
・[Status_DoNotEdit]セクションは動作中の状態保存用です。手動編集しないでください。

**********************************
********** セーフモード **********
**********************************

・短時間（60秒以内）に3回起動するなど、起動失敗によるループに入っていると判断した場合、次回の起動がセーフモードとなります。
・これによりExplorerが落ち続けて、タスクマネージャーからでないとTClockが止められなくなる事態を回避できる可能性があります。
・セーフモードでは、タスクトレイの書式先頭に"[SafeMode]"の表示が現れます。
・セーフモード時の右クリックメニューは意図的に制限され、主に『INI Recovery...』、再起動、終了を行うためのメニューになります。
・『INI Recovery...』は、古いini項目、既定値だけの不要な項目、旧形式の互換項目、UTF-8移行時の残り項目などを点検・整理するための機能です。通常の設定変更はプロパティから行ってください。
・起動間隔が60秒を超えると連続起動回数の判定はリセットされ、セーフモード中に手動再起動または終了するとセーフモードは解除されます。

**********************************
********** MinimalMode **********
**********************************

・[ETC] MinimalMode=1にすると、機能を限定した状態で起動します。書式表示のみの最小限の使用する機能で利用できます。
・MinimalModeでは右クリックメニューが終了のみになるなど、一部の機能や設定変更が制限されます。
・設定を変更する場合は、tclock-win11.iniの[ETC] MinimalMode=0に戻してからTClockを再起動してください。

********************************************
tclock-win11.ini設定項目 (値はデフォルト値)
********************************************

※ここに記載した値は、内蔵の既定値または代表的な初期値です。初期値と同じ項目はiniに書かれない場合があります。
※通常はプロパティから設定してください。手動編集する場合は、TClockを終了するか、編集後にTClockを再起動してください。

[Main]セクション
DebugLog = 0
TRUE(1)ならデバッグ用ログファイルの生成を行う。手動設定用。AutoClearLogFile=0だとどんどんファイルが大きくなるので注意。

NormalLog = 1
TRUE(1)なら通常動作記録用のログファイルの生成を行う。手動設定用。起動時にログファイルのサイズが10KBを超えている場合は以前のデータをクリアします。

AutoClearLogFile = 1
デバッグログファイルの肥大化を防ぐため、一定量ごとにファイルをクリアするかどうか。TRUE(1)ならクリアする。FALSE(0)ならクリアしない。

AutoClearLogLines = 1000
ログファイルをクリアするおおよその行数。厳密ではありません。

AutoRestart = 1
エクスプローラがクラッシュしたときに再起動するかどうか。
まれに、TRUE(1)にしてTClockのプロセスは復活したのに時計の改造が行われない場合や、FALSE(0)にしても、タスクトレイ表示が消えてるにもかかわらずプロセスが残る場合があるので注意してください。
その場合はタスクマネージャーからtclock-win11のプロセスを強制終了してください。

CompactMode = 0
通常はFALSE(0)。TRUE(1)にすると、ネットワーク関係など一部の機能を使わない機能限定モードになります。
起動に失敗する環境で、機能を減らして起動したい場合の手動設定用です。

EnglishMenu = 0
日本語UI環境ではFALSE(0)、それ以外ではTRUE(1)が初期値になります。TRUE(1)にすると、右クリックメニューが英語になります。右クリックメニューからも変更可能です。

AdjustThreshold = 200
何ミリ秒、秒表示タイミングが遅れるとタイマの修正を行うかの閾値。100-500の間の値で変更できますが、変更しないことをお勧めします。
500にすると修正はかかりませんが、どんどん遅れるわけではなく、時々秒表示が飛ぶだけです。
一方、小さくすればある程度正確になる傾向はありますが、TClockのアルゴリズム上、秒表示は参考程度です。
この設定値もms単位ですが、実際にはmsの精度はありません。PC(OS)のタイマ機能が不安定になる場合があるので、AdjustThresholdをどんなに小さく設定しても、10秒に1回しか補正はかかりません。

EnableOnSubDisplay = 1
TRUE(1)ならサブディスプレイ側の時計表示を有効にします。

OffsetClockMS = 0
時計表示の時刻をミリ秒単位でずらします。通常は0のままにしてください。プロパティの書式ページからも設定できます。

ShowTrayIcon = 1
TRUE(1)ならTClockの通知領域アイコンを表示します。プロパティのその他ページからも設定できます。

[Win11]セクション
Windows11のタスクバーや通知領域との位置合わせ、背景色取得などに関する設定です。通常はプロパティのWindows11対応ページから設定してください。

AlignTaskbarLeft = 1
Windows11のタスクバー配置を左寄せにする設定です。初期値と同じ場合はiniに書かれない場合があります。

AdjustCutTray = 0
タスクトレイ周辺の切り取り位置調整用。表示ずれがある場合の詳細調整用です。

AdjustWin11ClockWidth = 0
Windows11タスクバー上の時計領域幅の調整用。通常は変更しないでください。

AdjustDetectNotify = 0
通知領域検出位置の調整用。通常は変更しないでください。

AdjustWin11IconPosition = 1
Windows11のタスクバーアイコン位置調整を行うかどうか。

EnableWin11NotifyIcon = 0
現在は実装上常に無効です。手動で1に変更しても反映されません。

ExperimentalDisplayBackend = 0
実験的な表示バックエンドを使うかどうか。通常はFALSE(0)のままにしてください。

[Status_DoNotEdit]セクション
動作中のデータ、復旧用の情報、環境から得た一時情報を保存します。
手動での編集は無効です。誤動作を避けるため、編集しないでください。

代表的な項目:
SafeMode:		セーフモード状態です。
SafeModePendingOnce:	次回起動時にセーフモードへ入るための一時フラグです。
LastLaunchTimeStamp:	起動時刻の記録です。
PreviousLTEProfNumber:	前回にインターネット接続がLTE(WAN)で成立した際のプロファイル番号です。
PreviousLTEProfName:	前回にインターネット接続がLTE(WAN)で成立した際のプロファイル名です。
BatteryLifeAvailable:	バッテリ残量情報が取得できるかどうか。
TimerCountForSec:	タイマ処理の調整用パラメータです。
CountAutoRestart:	自動再起動回数の記録です。
Win11TClockMain:	Windows11向けメイン時計処理の状態記録です。
ClockWidth / ClockHeight:	現在の時計表示領域サイズの記録です。
LastExitUser:	ユーザー操作による終了かどうかの記録です。
MinimalDefaultsVersion:	MinimalMode用既定値の適用管理用です。

古いバージョンのiniには、現在は使われない状態項目が残っている場合があります。必要に応じてセーフモード時の『INI Recovery...』で点検してください。

[VPN]セクション
VPNインジケータ表示(書式"VPNS")のための検出キーワード。
VPNKeywords=VPN
VPNExcludeKeywords=

・VPNKeywordsは、VPN接続とみなすアダプタ名キーワードをカンマ区切りで指定します。
・VPNExcludeKeywordsは、VPNKeywordsに一致してもVPN扱いしないアダプタ名キーワードをカンマ区切りで指定します。除外指定のほうが優先されます。
・古いiniで使われていたVPN_Keyword1～5、VPN_Exclude1～5も互換のため読み込まれますが、現在は上記のカンマ区切り形式を推奨します。
※コントロールパネルに現れないアダプタ名は、たとえば"TCP Monitor Plus"のIF詳細情報取得機能などで得てください。
※文字色設定は[Color_Font]セクションにあります。

[ETC]セクション
ZombieCheckInterval=10 (5 - 300)
何秒に1回、タスクトレイへのフックの維持を確認するか。
TClockのプロセスが動いているのに時計の改造に失敗している『ゾンビ状態』になっていないかを確認します。
ゾンビ状態になった際に再起動するか、終了するかは、AutoRestartの設定に従います。

LTEString = LTE
LTE書式の際に、LTE(WAN)接続成立時に表示される文字列。右クリックメニューにも反映されます。

LTEChar = L
ICP書式等において、LTE(WAN)接続成立時に表示される文字です。(先頭一文字のみ有効)

MuteString = *
VM書式において、ミュート時に表示される文字列です。

NetMIX_Length = 10
NMX1およびNMX2書式の文字列幅です。

SSID_AP_Length = 10
SSIDおよびAPN書式の文字列幅です。

EthernetKeywords=
イーサネットアダプタを判定するキーワードをカンマ区切りで指定します。
古いiniで使われていたEthernet_Keyword1～5も互換のため読み込まれますが、現在はEthernetKeywordsを推奨します。

SelectedThermalZone=0
温度表示で参照するサーマルゾーン番号です。通常はプロパティのその他ページから設定してください。

MinimalMode=0
TRUE(1)にすると機能限定のMinimalModeで起動します。トラブル時や機能を減らして動かしたい場合の設定です。
MinimalModeでは右クリックメニューや一部機能が制限され、通常の設定変更ができない場合があります。解除する場合はMinimalMode=0に戻して再起動してください。

ExitExtensionsOnTClockExit=0
TRUE(1)ならTClock終了時に連携拡張も終了します。

GipEnabled=0
グローバルIPアドレス取得([GIP]書式)を有効にするかどうか。

GipRefreshHours=6
グローバルIPアドレスの再取得間隔(時間)です。

GipProvider=ipify
グローバルIP取得に使うプロバイダです。プロパティのキーワードページから選択できます。

GipJsonField=ip
カスタムプロバイダ利用時に、JSONからIPアドレスとして読むフィールド名です。

GipLastValue=N/A
最後に取得したグローバルIPアドレスの記録です。通常は手動編集しません。

AdditionalMountPath0～9
ドライブをNTFSマウントしたフォルダのフルパスを記入すると、ドライブレター:0～9としてHDD容量の書式が使えるようになります。NTFSマウントが解除された場合はフォルダの親ドライブの情報を表示します。HDD容量の書式については、従来のTClock2chカスタム書式を参照してください。
※例: 『HT[A-Z]M = [A-Z]ドライブの合計サイズ (MB単位)』という書式で、[A-Z]のところに0から9の数字を入れて使います。
